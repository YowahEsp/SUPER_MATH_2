# SUPER MATH 2

Colección de aplicaciones interactivas de matemáticas, sucesora de [SUPER MATH CODE](https://yowahesp.github.io/SUPER__MATH__CODE/). Cada aplicación es un único archivo HTML autocontenido (HTML + CSS + JavaScript, sin dependencias ni proceso de compilación) y funciona en cualquier navegador, también sin conexión.

**Portal:** https://yowahesp.github.io/SUPER_MATH_2/

## Aplicaciones

| Bloque | Aplicación | Carpeta |
|---|---|---|
| Numeración y decimales | Bloques 3D: unidades, decenas, centenas y millares | [`bloques-3d/`](bloques-3d/) |
| Numeración y decimales | Mundo Decimal | [`mundo-decimal/`](mundo-decimal/) |
| Numeración y decimales | Diez veces más, diez veces menos | [`diez-veces/`](diez-veces/) |
| Potencias | Potencias: cuadrados y cubos | [`cuadrados-cubos/`](cuadrados-cubos/) |
| Potencias | Recta o exponencial: a·n frente a aⁿ | [`crecimientos/`](crecimientos/) |
| Divisibilidad | Descomposición en factores primos · M.C.D. y m.c.m. | [`factores-primos/`](factores-primos/) |
| Divisibilidad | Máximo común divisor | [`mcd/`](mcd/) |
| Divisibilidad | Mínimo común múltiplo | [`mcm/`](mcm/) |
| Fracciones | Fracciones con pizza | [`fracciones-pizza/`](fracciones-pizza/) |
| Fracciones | Operaciones combinadas con fracciones | [`fracciones-combinadas/`](fracciones-combinadas/) |
| Cálculo | Cuaderno de cálculo | [`cuaderno-calculo/`](cuaderno-calculo/) |

Cada aplicación está en `carpeta/index.html`, así que su dirección pública es `https://yowahesp.github.io/SUPER_MATH_2/carpeta/`.

## Notas

- *Cuaderno de cálculo* carga tipografías de Google Fonts; sin conexión usa las tipografías del sistema y funciona igual.
- *Bloques 3D* incluye Three.js (r128) dentro del propio archivo.
